# 公開手順（OpenAI Sites・既存プロジェクトへ更新）

公開は Sites コネクタを持つ Codex から行います。Claude Code のクラウド環境からは Sites に接続できません。

## 1. 新しいソースをWindowsパソコンに取り込む

- GitHub の `e-almighty/almighty` リポジトリ、ブランチ `claude/new-session-zmp19c` のフォルダ `almighty-connect/` が最新ソースです。
- ZIPで取る場合: https://github.com/e-almighty/almighty/archive/refs/heads/claude/new-session-zmp19c.zip を展開し、中の `almighty-connect` を使います。

## 2. Codex に貼る指示（そのままコピー）

```
GitHub の e-almighty/almighty ブランチ claude/new-session-zmp19c のフォルダ almighty-connect を取得し、
C:\Users\user\Documents\Codex\2026-09-29\new-chat\outputs\almighty-connect の中身をこれで置き換えてください
（node_modules、.wrangler、.env、.sites-runtime は残してよい）。
その後、同じフォルダで次を実行してください。
  npm run install:ci
  node node_modules/typescript/bin/tsc --noEmit
  npm run build
build が成功したら、dist 全体（dist/.openai/hosting.json と dist/.openai/drizzle/ を必ず含める。
.wrangler と .env は含めない）を、既存の Sites プロジェクト appgprj_6abb820d4a2c8191857acf7a38dd27ad に
新しいバージョンとして保存・公開してください。前回と同じ方法（dist を tar にまとめて Sites の save/deploy）で構いません。
新しいプロジェクトは作らない。アクセス設定（所有者のみ・非公開）は変えない。
D1 マイグレーション 0002_odd_frank_castle（push_keys / push_subscriptions）が公開時に適用されたことを確認し、
deployment の状態が succeeded になったことを読み取りで確認して報告してください。
```

## 3. 公開後の確認

1. iPadのSafariで https://almighty-support-desk.almighty.chatgpt.site/reception を開く。
2. 画面上部に「受信接続版 10/2c」と「ログイン: （メールアドレス）」が出ていれば新しい版です。
3. 店舗側 https://almighty-support-desk.almighty.chatgpt.site/ でも同じメールアドレスが出ることを確認する。
4. 受付iPadで「ホーム画面に追加」→アイコンから開く→「スリープ中も通知を受け取る」→通知を許可。
5. 受付iPadをスリープさせ、店舗側で「三宮を呼び出す」。ロック画面に通知が出れば成功。
