このページについて

  • 青いボタン はインターネットのページを開きます　どの端末からでも開けます
  • 明るい青のボタン は 保管庫（Dropbox）のファイルを Dropbox の画面で開きます　会社の Dropbox アカウントでログインしている端末で使えます　別のアカウントだと「フォルダは存在しません」と出ます
  • 「ブラウザで発表する」などの HTML のスライドは Dropbox の画面では文字しか出ません　PDF か PowerPoint のボタンを使ってください
  • claude.ai のアドレスのアプリは ログインを求められたら いつものアカウントでログインしてください
  • 中身の正本は 保管庫の 00_HOME → 保管庫 → 玄関データ.json です　新しく載せたいものができたら AIに「保管庫に載せて」と言ってください
