# ANALYSIS_RULES — 線の引き方と解説文のルール（STEP 3 で SHO と調整中）

**基本思想：数値解析 → ライン候補決定 → 描画 → AI 解説。** AI がチャート画像を目視して「ここが高値っぽい」と線を引くことはしない。
このルールは [[05_SKILLS/fx-morning-report/SKILL|fx-morning-report]] に書かれていた SHO の優先順位を出発点にしている。STEP 3 で SHO が本物のチャートを見て直す。

設定値はすべて `config/analysis.yaml` にある。ここに書く数字は 2026-10-03 時点の初期値。

## 0. SHO の方針（2026-10-04 ヒアリング・随時更新）

決まったこと（反映済み）:

- 高値・安値の見つけ方（左右 5 本）は **そのままで OK**
- サポート・レジスタンスは **もっと強く、太く、はっきり**「ここがサポート／レジスタンス」と分かるように出す。**サポート＝赤、レジスタンス＝緑**（初版と逆）。右端に色付きの箱で「サポート 156.587」のように明記
- 根拠がものすごく欲しい。線 1 本ごとに「なぜそこか」を言語化する

- **EMA は 20・50・200 の 3 本**（SHO 決定・2026-10-04）。橙＝20、青＝50、紫＝200。3 本の並び（パーフェクトオーダー）を解説文で言語化する → 反映済み
- トレンドライン単体ではなく **平行チャネル**で持つ。**中央線も描く**（SHO 決定・2026-10-04）→ 反映済み（下の「4. チャネル」）
- 線 1 本ごとに「なぜそこか」を解説文の「根拠」に書く → 反映済み

決まったこと（これから反映）:

- **フィボナッチ**を使う（リトレースメント。斜めに引くフィボナッチ・チャネルも候補）
- インジケーターは **スクイーズモメンタム（SQZMOM）** が大好き。**RSI のダイバージェンス**も見る。これらの評価を解説文で言語化する
- 発信の形：**4時間足・1時間足・5分足の 3 枚のチャート**と、それぞれの解説文を 1 セットで出す

まだ聞いていないこと:

- サポレジの本数（各 3 本のままか）
- チャネルの平行線を「期間内の最も離れた高安（ヒゲ含む）」で決めてよいか、確定スイングだけにするか（`channel_far_point`）
- EMA200 を相場環境の点数に入れるか（今は解説文で触れるだけ）
- フィボナッチの起点・終点（直近の大きな波か、日足の波か）
- SQZMOM と RSI を画像に描くか（サブパネル）、解説文だけにするか

### EMA の説明（2026-10-04 に SHO へ回答した内容）

- 20 と 50 は Claude が初期値として選んだもので、SHO の決定ではない。根拠は ①fx-morning-report に「21EMA・200MA」が書かれていた ②Phoenix 5分足版で日足 EMA50 を方向ゲートに使っていた ③多くのトレーダーが見る組み合わせなので、線が機能しやすい
- 2 本にした理由は「終値と遅い線の上下＝方向」「速い線と遅い線の上下＝勢い」「遅い線の傾き」の 3 つで相場環境を決めるのに 2 本で足りるから。初版は複雑にしない方針だった
- 3 本目（EMA200）を足すと「大局」が画像の中で見える。4時間足の EMA200 ≒ 約 33 営業日。足すこと自体は賛成。SHO が普段使っている本数・期間に合わせる

## 1. スイング高値・安値

- Pine の `ta.pivothigh / ta.pivotlow` と同じ。左 5 本より高く（低く）、右 5 本以上（以下）なら確定
- 右 5 本が確定して初めて決まるので、直近 5 本の中に確定スイングは無い
- 同じ種類（高値→高値）が続いたら極値の方だけ残す（ZigZag 風）。トレンド判定とトレンドラインはこの「交互スイング」を使う

## 2. サポート・レジスタンス

1. 解析範囲（300 本 ≒ 50 日）のスイング高値・安値をすべて集める
2. 価格差が **ATR(14) × 0.6** 以内のものを 1 つの価格帯にまとめる（クラスタ）
3. 価格帯の値は、まとめたスイングの中央値
4. その価格帯に、ローソク足のヒゲが何回触れたか（反応回数）を数える。連続する足は 1 回
5. 重要度 ＝ 反応回数 ＋ まとめたスイング数 × 0.5 ＋ 直近性（最後に触れてからの経過で減衰、最大 1.5）＋ 心理的節目（XX0.00 / XX5.00 に近ければ +0.5）
6. 現在値より下 → サポート、上 → レジスタンス。重要度順に **各 1〜3 本**
7. ライン同士が **ATR × 1.0** より近い場合は、重要度の低い方を間引く（画像をラインだらけにしない）
8. 画像には、描く足の高安 ± ATR の範囲に入るラインだけ描く。範囲外のラインは解説文にだけ残す

### fx-morning-report に書かれていた優先順位（参考・今後の反映候補）

1. 4時間足の直近スイング高値・安値 → 実装済み（上の手順）
2. 日足の前日高値・安値 → **未実装**（候補に加える予定）
3. 週足・日足の主要サポレジ → 未実装
4. 心理的節目 → 重要度ボーナスとして実装
5. 移動平均（21EMA、200MA） → EMA20/50 を描画。ラインとしては扱わない
6. フィボナッチ → 未実装

## 3. 相場環境（5 分類）

スコア方式。4 項目を +1 / 0 / -1 で合計する。

| 項目 | +1 | -1 |
|---|---|---|
| 終値と EMA50 | 上 | 下 |
| EMA20 と EMA50 | 上 | 下 |
| EMA50 の傾き（直近 10 本の変化が ATR × 0.2 を超える） | 上向き | 下向き（超えなければ 0） |
| 直近 2 組の高値・安値 | HH/HL（切り上げ） | LH/LL（切り下げ）（混在は 0） |

| 合計 | 分類 |
|---|---|
| +3 以上 | 強い上昇 |
| +2 | 弱い上昇 |
| -1〜+1 | レンジ |
| -2 | 弱い下落 |
| -3 以下 | 強い下落 |

4時間足と日足の方向が一致なら強め、逆なら慎重に（fx-morning-report）。日足は「前日終値が日足 EMA50 の上か下か」で見る（Phoenix 5分足版の方向ゲートと同じ考え方）。

## 4. チャネル（平行チャネル・中央線つき）

**基準線（トレンドライン）の決め方**

- **上昇**：直近 6 個の交互スイング安値から 2 点（後の点が高い）を選んで結ぶ。2 点の間で終値が線を割っていたら無効
- **下降**：スイング高値で同じ
- 接触：ヒゲが線から **ATR × 0.3** 以内なら接触。連続する足は 1 回。3 点目以降の接触があれば「有効性あり」
- 複数候補からは「割られていない線 ＞ 接触が多い線 ＞ 新しい線」の順で 1 本だけ選ぶ
- 2 点目より後で終値が線を越えていたら「ブレイク」。**ブレイクから 10 本より経った線は描かない**
- 線の現在値が現在値から **ATR × 6** より離れていたら描かない
- **レンジ相場では無理に引かない。** 3 点以上の接触がある線だけ残し、原則はレンジ上限・下限（サポレジ）を優先表示
- 上昇相場では上昇ラインだけ、下落相場では下降ラインだけ探す

**チャネルの作り方（2026-10-04 SHO 決定・反映済み）**

1. 上昇チャネルの**下限** ＝ 上の基準線（安値を結んだ線）
2. **上限** ＝ 下限と平行で、基準線の起点から現在までの間で「基準線から最も上に離れた高値（ヒゲ含む）」を通る線。期間内の値動きがすべてチャネルの中に収まる
3. **中央線** ＝ 上限と下限のちょうど真ん中（破線）
4. 下降チャネルは上下を逆にして同じ（上限＝高値を結んだ基準線、下限＝最も下に離れた安値を通る平行線）
5. 現在の終値がチャネルのどこにいるかを「上限寄り／中央より上／中央より下／下限寄り／上抜け／割れ」で言語化する
6. 根拠として「下限線は m/d と m/d の安値を結んだ線（接触 n 回）。上限線は m/d の高値を通る平行線（接触 m 回）」を解説文に書く
7. 画像では上限・下限＝黒の実線、中央＝灰の破線。右端に「上昇CH上限 160.381」のように値を明記

## 5. 投稿画像

- 入れるもの：USDJPY／時間足／現在値／ローソク足（直近 120 本）／**サポート（赤・太線）／レジスタンス（緑・太線）**、右端に色付きの箱で「サポート 156.587」と明記／**平行チャネル（黒の実線＝上限・下限、灰の破線＝中央）**／EMA20（橙）・EMA50（青）・EMA200（紫）／分析日時。価格の目盛りは左、右端はラベル専用
- 入れないもの：SL/TP 候補（必要になったら）、多すぎるライン
- 1600×900 px（X でスマホから見て読める太さ・文字サイズ）
- 右下に「テクニカル分析の参考情報であり、投資助言ではありません。」

## 6. 解説文

順番：現在値 → 相場環境（根拠つき）→ 日足の大局 → サポート → レジスタンス → トレンドライン → 上方向シナリオ → 下方向シナリオ → 次に注目する価格帯

- 「必ず」「絶対」「買い」「売り」の断定は使わない。「〜に注目」「〜が焦点」「〜の可能性」
- 数字は小数 3 桁（157.874）
- X 投稿案は別に短文で作る（↑↑ / ↑ / → / ↓ / ↓↓ の矢印、R/S の価格、TL の状態、ハッシュタグ）
