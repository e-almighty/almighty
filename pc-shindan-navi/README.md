# パソコン診断ナビ

調子の悪いパソコンをお持ち込みいただいたときに 「はい／いいえ」の3問と 症状の選択（8つのボタン）でお困りの内容を切り分け 次のステップ（店頭チェック／お預かり診断）を提案する店頭受付用のガイドです（iPad向け）

- 画面の作りと操作は「パソコン相談ナビ」（pc-navi）と同じです（style.css はそのまま流用）
- 回答は個人を特定しない形で端末内に記録されます
- 裏メニュー（右上の「約2分・全4問」を3秒以内に5回タップ）で 集計・CSV書き出し・送信先の設定ができます
- 送信先（Googleスプレッドシートの受付窓口）は未設定です　`gas/Code.gs` で窓口を用意してから 裏メニューでURLと合言葉を入れてください（相談ナビの窓口とは列が違うので 別のスプレッドシートにします）

## 質問の流## 質問の流れ（全4問）

最初の画面に 基本診断費 2,200円 がかかる旨を表示します（`app.js` の `FEE`）

1. 残したい写真や書類などのデータは入っていますか？（はい／いいえ）
2. Windowsに入るときのパスワード（PIN）はわかりますか？（はい／いいえ）
3. 症状が出る少し前に心当たりはありますか？（はい／いいえ）
4. いちばん近いお困りの症状をひとつ選ぶ（8つのボタン）

| 症状 | 次のステップ |
|---|---|
| 電源が入らない／Windowsが起動しない／Windowsでエラーが出る／ウイルス感染・警告画面／動作が遅い・固まる | お預かり診断 |
| インターネットにつながらない／メールができない／その他のご相談 | 店頭チェック |

メーカー修理への案内は行いません（次のステップは店頭チェックとお預かり診断の2つだけ）

定を直すところ（app.js）

- `FEE` … 基本診断費の表示
- `QUESTIONS` … はい／いいえの3問（質問文・選択肢・結果ページに足す一文 `note`）
- `SYMPTOMS` … 8つの症状ボタン（文字・小さな説明・結果の見出し・当店で確認すること・次のステップ `next`）
- `NEXT` … 次のステップ2つの名前と説明（お店の受付メニューに合わせて直す）
- 画面の文字を変えたら `sw.js` の `CACHE` の番号を1つ上げる（ホーム画面に追加したiPadに新しい版が届く）
