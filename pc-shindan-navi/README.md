# パソコン診断ナビ

調子の悪いパソコンをお持ち込みいただいたときに 「はい／いいえ」で答える質問（7〜10問）でお困りの内容を切り分け 次のステップ（店頭チェック／お預かり診断／修理・メーカー相談）を提案する店頭受付用のガイドです（iPad向け）

- 画面の作りと操作は「パソコン相談ナビ」（pc-navi）と同じです（style.css はそのまま流用）
- 回答は個人を特定しない形で端末内に記録されます
- 裏メニュー（右上の「約3分・最大10問」を3秒以内に5回タップ）で 集計・CSV書き出し・送信先の設定ができます
- 送信先（Googleスプレッドシートの受付窓口）は未設定です　`gas/Code.gs` で窓口を用意してから 裏メニューでURLと合言葉を入れてください（相談ナビの窓口とは列が違うので 別のスプレッドシートにします）

## 質問の流れ

```
1 電源を入れると いつもの画面（デスクトップ）まで進みますか？
├ 進まない
│  2 電源ボタンを押すと ランプや音など反応がありますか？
│  ├ いいえ → 3 充電器をつないだままでも反応しませんか？ ……… 電源が入らない
│  └ はい → 3 画面に何か表示されますか？
│      ├ いいえ ……………………………………………………………… 画面が映らない
│      └ はい → 4 「回復キーを入力してください」の青い画面ですか？
│          ├ はい → 5 48桁の回復キーを用意できそうですか？ ……… 回復キーの画面が出る
│          └ いいえ → 5 ログイン画面は出るがパスワードがわからない？
│              ├ はい → 6 Microsoftアカウントはわかりますか？ … パスワードがわからない
│              └ いいえ → 6 再起動を繰り返す・自動修復で止まる？ … Windowsが起動しない
└ 進む
   2 ウイルス感染の警告や電話番号が表示されましたか？
   ├ はい → 3 番号に電話したり操作したりしましたか？ ………… ウイルス感染・警告画面
   └ いいえ → 3 インターネットやメールのことでお困りですか？
       ├ はい → 4 ホームページは開けますか？
       │   ├ いいえ → 5 ほかの機器は同じWi-Fiでつながりますか？ … インターネットにつながらない
       │   └ はい → 5 メールのパスワードや書類はありますか？ …… メールができない
       └ いいえ → 4 エラー・固まる・極端に遅い などがありますか？
           ├ はい → 5 いちばん困っているのは「遅い・固まる」？
           │   ├ はい …………………………………………………………… 動作が遅い・固まる
           │   └ いいえ → 6 特定のソフトを使うときだけ出ますか？ … エラーが出る
           └ いいえ → 5 機器のことでお困りですか？
               ├ はい → 6 本体の部品のことですか？ … はい：本体の部品の不調／いいえ：つないで使う機器の不調
               └ いいえ ……………………………………………………………… その他のご相談

切り分けのあと 全員に共通の4問
  残したいデータは入っていますか？ → 控え（バックアップ）はありますか？
  → Windowsのパスワードはわかりますか？ → 症状が出る少し前に心当たりはありますか？
```

次のステップの決め方は `app.js` の `nextKey()` にまとめてあります（例：電源が入らない＋充電器でも反応なし → 修理・メーカー相談／警告画面で電話や操作をした → お預かり診断）

## 文面や判定を直すところ（app.js）

- `QUESTIONS` … 質問文・選択肢・分岐（`next`）・お困りの内容の決定（`cat`）・結果ページに足す一文（`note`）
- `CATS` … お困りの内容の名前と 結果ページの見出し・当店で確認すること
- `NEXT` … 次のステップ3つの名前と説明（お店の受付メニューに合わせて直す）
- `nextKey()` … お困りの内容と答えから 次のステップを選ぶ規則
- 画面の文字を変えたら `sw.js` の `CACHE` の番号を1つ上げる（ホーム画面に追加したiPadに新しい版が届く）

## 公開のしかた

GitHub Pages で公開すると https でホーム画面に追加でき オフラインでも動きます　このフォルダをそのまま新しいリポジトリ（例 `pc-shindan-navi`）の一番上に置くか このリポジトリで Pages を有効にして `/almighty/pc-shindan-navi/` を開きます
