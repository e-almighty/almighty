# パソコン診断ナビ

調子の悪いパソコンをお持ち込みいただいたときに 技術スタッフにつなぐまでの受付をする店頭用のガイドです（iPad向け）　細かな診断や解決はここではしません

- 画面の作りと操作は「パソコン相談ナビ」（pc-navi）と同じです（style.css はそのまま流用）
- 回答は個人を特定しない形で端末内に記録されます
- 裏メニュー（右上の「約2分・全4問」を3秒以内に5回タップ）で 集計・CSV書き出し・送信先の設定ができます
- 送信先（Googleスプレッドシートの受付窓口）は未設定です　`gas/Code.gs` で窓口を用意してから 裏メニューでURLと合言葉を入れてください（相談ナビの窓口とは列が違うので 別のスプレッドシートにします）

## 画面の流れ（全4問）

最初の画面に **基本診断費 2,200円** がかかる旨をいちばん大きく表示します（`app.js` の `FEE`）

1. 残したい写真や書類などのデータは入っていますか？（はい／いいえ）
2. Windowsに入るときのパスワード（PIN）はわかりますか？（はい／いいえ）
3. 症状が出る少し前に心当たりはありますか？（はい／いいえ）
4. いちばん近いお困りの症状をひとつ選ぶ（8つのボタン：電源が入らない／Windowsが起動しない／インターネットにつながらない／メールができない／Windowsでエラーが出る／ウイルス感染・警告画面／動作が遅い・固まる／その他のご相談）

→ 「この画面を担当者にお見せください」（症状と3つの回答・スタッフ記入欄「受付した／見送り」）

## 文面を直すところ（app.js）

- `FEE` … 基本診断費の表示
- `QUESTIONS` … はい／いいえの3問（質問文・選択肢）
- `SYMPTOMS` … 8つの症状ボタン（文字・小さな説明）
- 画面の文字を変えたら `sw.js` の `CACHE` の番号を1つ上げる（ホーム画面に追加したiPadに新しい版が届く）

## 公開のしかた

GitHub Pages で公開すると https でホーム画面に追加でき オフラインでも動きます　このフォルダをそのまま新しいリポジトリ（例 `pc-shindan-navi`）の一番上に置くか このリポジトリで Pages を有効にして `/almighty/pc-shindan-navi/` を開きます
