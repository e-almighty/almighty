# くわしい仕様

## このツールが作るもの

**スライド解説動画、1形式だけです。**

- 画面はスライド（見出しと箇条書き。任意で絵）
- 声はナレーション1人
- それに字幕

キャラクターの立ち絵、2人の掛け合い、顔出し、実写映像は**作れません。**

### 他の形式は、この制作キットでは作れません

**この制作キットは、スライド解説の専用ツールです。**キャラクターや掛け合いには対応していません。

本書を読んだあなたは、動画1本がどんな部品でできているかを知っています（第0部）。
**応用は、ぜひご自身で試してみてください。**

ただし、この制作キットを作り替える形ではなく、**別の仕組みとして**取り組まれることをおすすめします。
ここに手を入れると、スライド解説のほうが動かなくなります。

---

## ★はじめに：PDFとこのファイルの役割はちがいます

よくある勘違いなので、先にお伝えします。

| | 誰が読むか | 何のために |
|---|---|---|
| **PDF（本書）** | **あなた** | **なぜそうするのか**を理解するため |
| **このフォルダの中身** | **Claude** | **何をするか**の指示 |

### ★PDFをClaudeに読み込ませないでください

**必要ありません。**そして、やらないほうがよいです。

本書は約15万字あります。読み込ませると、**動画を作り始める前に会話の容量をほとんど使い切ってしまいます。**

**Claudeに必要な指示は、すべてこのフォルダの中に入っています。**

### やることは、これだけです

```
① このフォルダの中身を、制作用フォルダにまるごとコピーする
② そのフォルダで Claude Code を開く
③ 「/はじめる」と打つ
```

`CLAUDE.md` は、**Claude Codeが起動したときに自動で読み込みます。**
あなたが「読んで」と頼む必要はありません。

`.claude/commands/` の中身も、`/名前` と打った瞬間に読まれます。
**普段は開くことも、中を覚えることもありません。**

## 準備（初回だけ・10分）

### 1. `.env` にキーを書く

`.env.例` を `.env` という名前でコピーして、キーを書き込みます。

```
ELEVENLABS_API_KEY=（あなたのキー）
OPENAI_API_KEY=（あなたのキー）
```

> ElevenLabsのキーは https://elevenlabs.io の設定画面から（有料プラン推奨・第3章）。
> OpenAIのキーは、**読み間違いの機械チェック**に使います（1本あたり数円）。
> 使わない場合は空のままでも動きます。

### 2. `CLAUDE.md` を埋める

（　）の部分を自分のチャンネルの内容にします。順番は `02_制作キットの使い方.md` のとおりです。

**【固定・変更禁止】だけは必ず自分で書いてください。**ここはAIに提案させない項目です。

### 3. ★声を決める（いちばん大事です）

```
/00_声を選ぶ
```

または直接：

```
python3 ツール/compare_voices.py --おすすめ          # まずはこれ（6声を聞き比べ）
python3 ツール/compare_voices.py                    # 共有ライブラリの日本語40件を一覧
python3 ツール/compare_voices.py ID1 ID2 ID3        # 指定した声で比較
```

ここに出るのは **ElevenLabsの共有ライブラリの声**です。追加の契約なしに、そのまま使えます。

**テンプレートに既定の声はありません。**`CLAUDE.md` の「声」は空欄です。

**必ずご自身で選んでください。**声はチャンネルの印象そのもので、あとから変えると全編作り直しになります。

数字を読ませて確かめた6声を用意してあります。

| 声 | 系統 | 速さ |
|---|---|---|
| Mitsuki | 女性・若・明るめ | 229字/分 |
| Yuki | 女性・若 | 264字/分（★十か月を誤読） |
| Haru | 女性・穏やか | 290字/分 |
| Kana | 女性・落ち着き | 327字/分 |
| Ryu | 男性・中年・落ち着き | 280字/分 |
| Riku | 男性・中年・深め | 292字/分 |

**Creatorプラン（月22ドル）があれば、6声とも追加手続きなしで使えます。**
追加料金も、文字数の割増もありません。

**声によって尺が4割変わります。**声を決めてから台本の長さを決めてください。

★別の声を選ぶときは、**取り下げの予告期間**を確認してください。30日予告の声もあります。

**5秒で決めないでください。通しで聞いてください。**
日本語ラベルが付いていても、**聞くと訛りを感じる声が混じっています。**
決まったら、その声のIDを `CLAUDE.md` と `script.json` に書きます。

### 4. 動作確認

```
python3 ツール/make_slides.py script_例.json
```

`出力/slides/` にPNGが2枚できれば、準備完了です。

## 使い方

### ★まずはこの2つだけ覚えてください

```
/はじめる       ← 一度だけ。契約・設定・チャンネル設計・声決め
/動画をつくる    ← 毎回。会話で1本つくる
```

**これだけで動画が作れます。**Claudeが順番に聞いてくれるので、手順を覚える必要はありません。

`/はじめる` は、いまどこまで済んでいるかを先に調べてから、
**足りないところだけ**案内します。途中でやめても、続きから再開できます。

## 細かく進めたいとき（2通り）

### A. 工程ごとに進める

Claude Code で、順番に呼びます。

```
/01_構成  相続の基礎控除について
      ↓  構成を確認して、OKを出す
/02_台本
      ↓  台本を声に出して読む＋ check_slides.py で箇条書きを確認
/03_スライド
/04_音声
      ↓  読み間違いの一覧が出る → 直す → 通しで聞く
/05_組み立て
```

**各工程で止まって確認できる**ので、手戻りが小さくて済みます。

### B. まとめて走らせる（慣れたらこちら）

```
/1本作る  5
```

構成ができた時点で**一度だけ止まります**。そこでOKを出せば、完成まで走ります。

## 直したいとき

| 直したいもの | やること |
|---|---|
| 構成 | `/01_構成` からやり直す（いちばん安い） |
| セリフを1行 | `script.json` の該当行を直す → `/04_音声`（変わった行だけ作り直されます） |
| 読み間違い | `script.json` のその行に `read` を足す → `/04_音声` |
| BGMの音量 | `ツール/build_video.py` の `BGM_VOL`／`BGM_DUCK` を直す → `/05_組み立て` |
| 曲の切り替え位置 | `script.json` の `section` を直す → `/05_組み立て` |
| スライドの文字 | `script.json` の `heading` `bullets` を直す → `/03_スライド` |
| 画風 | `ツール/make_slides.py` の `STYLE` を直す → `/03_スライド` |
| 絵の雰囲気 | `ツール/make_slides.py` の `ART_STYLE` を直す → `/03_スライド` |
| 絵の内容 | `script.json` の `art` を直す → `/03_スライド`（1枚1円ほど） |
| 字幕の大きさ | `ツール/build_video.py` の `SUB_SIZE` を直す → `/05_組み立て` |
| 字幕帯の色 | `ツール/build_video.py` の `BAND_COLOR` を直す → `/05_組み立て` |
| 字幕のめくりが速い／遅い | `ツール/subtitle_split.py` の `MAX_SEC`（1枚の最長秒数）を直す |
| 話し方が早口／間延び | `ツール/build_video.py` の `GAP_PERIOD` などを直す → `/05_組み立て` |

**工程は逆流させないでください**（第12章 12-5）。戻るほど作り直しが増えます。

## ★箇条書きと字幕を、同じ内容にしないでください

**ナレーションは字幕で全文が画面に出ます。**
その状態で箇条書きにも同じことを書くと、**画面に同じ内容が2回**出ます。

```
python3 ツール/check_slides.py script.json
```

言い換えになっている行を洗い出します。

| | 例 |
|---|---|
| ○ 数式 | 3,000万円＋600万円×人数 |
| ○ 数字 | 期限は10か月 |
| ○ 用語 | 基礎控除／代襲相続 |
| **× 言い換え** | **全員にかかるわけではない** |

**3つ埋めようとしないでください。**見出しだけの画面があっても構いません。

## 画面の分け方と、字幕のめくり

### 画面は「スライド」と「字幕帯」に分かれます

```
┌────────────────────────┐
│                        │
│   スライド 1920×858     │  ← ここに見出し・箇条書き・絵
│                        │
├────────────────────────┤
│   字幕帯 1920×222       │  ← ここに字幕（白文字）
└────────────────────────┘
```

**この分け方のおかげで、字幕とスライドが絶対に重なりません。**
背景が明るくても暗くても、字幕はいつも読めます。

### 字幕は「めくり」ます

ナレーション1文をそのまま出すと、**4〜6秒も画面が止まって見えます。**

そこで1文を短く割って、話の進みに合わせてめくります。

| | |
|---|---|
| 1枚 | **必ず1行**（2行にしない） |
| 1行の上限 | 28字 |
| 1枚の表示 | **1.4〜3.0秒** |
| 切る場所 | 句読点・助詞・文末表現のうしろ |

**字数だけでなく、表示秒数でも切ります。**ゆっくり読む声だと、28字でも5〜6秒かかるためです。

### 単語の途中では切りません

日本語は単語のあいだに空白がないので、何も考えずに切ると崩れます。

```
× 基礎／控除        熟語が割れる
× エレ／ベンラボ    カタカナ語が割れる
× 3,0／00万円      数字が割れる
```

`subtitle_split.py` が、切ってよい場所（句読点・助詞・文末表現のうしろ）だけで切ります。
**切る場所がなければ、上限を超えても切りません。**単語を割るよりましだからです。

**めくる位置は、音声が実際に息をついだところに合わせています。**
`build_video.py` が音声の無音を検出して、そこで切り替えます。だから声と字幕がずれません。

### 文と文のあいだに「間」が入ります

1行ずつ作った音声をそのままつなぐと、**文が終わった瞬間に次の文が始まって早口に聞こえます。**
そこで、行のあとに無音を入れています。

| 行の終わり | 間 |
|---|---|
| 。 | 0.40秒 |
| 、・ | 0.25秒 |
| ！ | 0.45秒 |
| ？ | 0.40秒 |
| 句読点なし | 0.30秒 |
| **シーンの最後** | **0.70秒** |

±12％だけ揺らしています（機械的に等間隔だと不自然なため）。
**同じ台本なら毎回同じ揺れ**になるので、直した箇所を聞き比べられます。

**そのぶん尺が伸びます。**実測で1行あたり約0.47秒、10分の動画なら1分前後です。
秒数は `build_video.py` の `GAP_` で始まる設定で変えられます。

## `script.json` の書き方

台本のデータです。`/02_台本` が自動で作りますが、手で直すこともできます。

```json
{
  "title": "動画のタイトル",
  "channel": "チャンネル名",
  "voice_id": "声のID",
  "scenes": [
    {
      "heading": "スライドの見出し（18字以内。絵ありなら12字以内）",
      "section": "導入",
      "art": "（任意）電卓と家と家族3人のアイコンが並ぶ図",
      "bullets": ["要点1（25字以内）", "要点2", "要点3"],
      "lines": [
        {"text": "ナレーション1文（40字以内）"},
        {"text": "基礎控除は3,000万円です。", "read": "基礎控除は三千万円です。"}
      ]
    }
  ]
}
```

### ★ `text` と `read` の使い分け

| | 何に使うか |
|---|---|
| **`text`** | **画面に出す字幕** |
| **`read`** | **音声に読ませる文**（省略したら `text` を読みます） |

読み調整が必要な行にだけ `read` を足してください。
これを分けているので、**「コーハイトー」が字幕に出る**ということが起きません。

### ★読み間違いは、機械で先に洗い出せます

```
python3 ツール/check_voice.py script.json
```

作った音声を文字起こしして、台本と突き合わせます。
**数字・固有名詞の読み間違いが、聞く前に一覧で出ます。**

```
・ シーン2 2行目
   台本 : これに相続人ひとりにつき六百万円を加算します。
   聞こえ: これに、相続に1人につき600万円を加算します。
   ・語の確認: 相続人
```

これは**耳の代わりではありません。**10分の動画で全行に集中し続けるのは難しいので、
**怪しい行を先に絞り込む**ためのものです。最後は必ず通しで聞いてください（第14章）。

## スライドに絵を入れる場合（任意・第13章）

`script.json` の各シーンに `"art"` を書き、`.env` に `OPENAI_API_KEY` があれば、
**自動で絵を作って右側に置きます。**

```json
{ "heading": "基礎控除はいくら？", "art": "電卓と家と家族3人のアイコンが並ぶ図" }
```

### 2層で作っています

| | どこで描くか |
|---|---|
| **文字・数字** | **HTML**（台本と必ず一致します） |
| **絵** | AI（gpt-image-2） |

**文字は絶対に絵に描かせません。**AIに数字を描かせると、台本と違う数字を勝手に描くことがあります。

### 費用

**1枚1円ほど**（quality `low`）。15枚で**約14円**です。

**同じ指示の絵は作り直しません。**台本の文字を直しても、絵の指示が変わらなければ0円です。

| | 1本の追加費用 | 月4本 | 月20本 |
|---|---|---|---|
| 文字だけ | 0円 | 約6,300円 | 約6,300円 |
| **絵あり（15枚）** | **約14円** | 約6,360円 | 約6,580円 |

**金額はほとんど変わりません。**判断すべきは費用ではなく、**待ち時間**です（下記）。

### 時間はかかります

絵は1枚ずつ作られます。**15枚だと、それなりに待ちます。**

急いで出したいときは、絵なしで作ってください。**台本はそのまま使えます。**
あとから絵の指示を足して、作り直すこともできます。

### 絵ありのときは、文字数の上限が変わります

| | 見出し | 箇条書き |
|---|---|---|
| 文字だけ | 18字以内 | 25字以内 |
| **絵あり** | **12字以内** | **17字以内** |

超えると2行に折れます。

### 絵の見せ方は2つあります

`ツール/make_slides.py` の `STYLE["layout"]` で切り替えます。

| | 見た目 |
|---|---|
| `card`（既定） | 濃紺の背景に、絵を白いカードで置く。落ち着いた印象 |
| `full` | 白い背景に、絵を大きく置く。明るく、解説動画らしい印象 |

**字幕の色を気にする必要はありません。**字幕は下の帯の中に入るので、
スライドが明るくても暗くても読めます。

**チャンネル全体で統一してください。**1本ごとに変えると、並べたときに揃いません。

### 絵柄を揃える

`ツール/make_slides.py` の `ART_STYLE` の1文が、**全スライドの絵柄を決めます。**
ここを変えるとチャンネル全体の雰囲気が変わります。1本ごとに変えないでください。

## BGMを入れる場合（第19章）

制作用フォルダに `bgm/` を作って、**似た雰囲気の曲を5〜8曲**入れてください。
あれば自動で使います。入れなければBGMなしで作ります。

曲は、`script.json` の `section` の区切りで切り替わります。

| やっていること | 数値 |
|---|---|
| 曲の切り替わり | 1.5秒重ねる |
| ふだんの音量 | 全体の8％ |
| ナレーション中 | **約1〜2％**まで自動で下げる（実測 約−14dB） |

**1本に同じ曲を流し続けないでください。**いちばん多い失敗です（第19章 19-2）。

### 動画ごとの音量は、自動でそろえています

声もBGMも **−16 LUFS**（YouTubeの基準に近い値）にそろえてから混ぜています。
そのため、**何本作っても音量が揃います。**`build_video.py` の `LOUDNESS` で変えられます。

音量の判断は、**翌日に、スマートフォンのスピーカーで**行ってください。
制作中の自分の耳は、聞き慣れて当てになりません（19-4）。

**本書の方法は、無料では実践できません。**ここは最初にご承知おきください。

### 1本ごとに増えるもの

| | 1本（10分）あたり |
|---|---|
| スライド（文字だけ） | **0円**（HTMLで作るため） |
| スライドに絵を入れる場合 | **約14円**（15枚・1枚1円ほど・任意） |
| 音声 | 2,700〜3,800文字（声によって変わります） |
| 組み立て | **0円**（ffmpeg） |

音声の文字数は**ElevenLabsの月間の枠から引かれます。**枠に収まっているかぎり、追加の支払いは発生しません。

つまり、**本数を増やしても月の支払いは変わりません。**

下の表は、月6,300円を本数で割ったものです。**払う額はどちらの行も6,300円**です。

| 月の本数 | 月の支払い | 1本あたりの負担 |
|---|---|---|
| 4本 | 約6,300円 | 約1,600円 |
| 20本 | 約6,300円 | **約320円** |

### ただし、天井があります

音声には月間の文字数の上限があります。10分の動画1本で2,300〜3,300字です（選んだ声の速さによります）。

`/04_音声` を実行すると、**残りの文字数と「あと何本つくれるか」を表示します。**

```
★ElevenLabsの残り：311,578字 / 317,915字（creatorプラン）
  → この動画と同じ長さなら、あと約 91 本つくれます
```

枠に届きそうなら、そのときにプランを上げるか判断してください。詳しくは第18章をご覧ください。

## ★尺の見積もりについて

**台本の長さは、選んだ声の速さで決まります。**本書の第14章で6声を実測した値です。

| 声 | 実測 | 10分に必要な字数 |
|---|---|---|
| Mitsuki | **229字/分** | 約2,300字 |
| Yuki | 264字/分 | 約2,600字 |
| Ryu | 280字/分 | 約2,800字 |
| Haru | 290字/分 | 約2,900字 |
| Riku | 292字/分 | 約2,900字 |

**いちばん遅い声といちばん速い声で、1,000字違います。**

2本目からは、その数字を使って台本の長さを決めてください。
