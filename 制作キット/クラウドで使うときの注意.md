# クラウド（Claude Code on the web）でこの制作キットを使うときの注意

この制作キットは、もともと**自分のパソコン（Mac / Windows）で Claude Code を開いて使う**ように書かれています。
Git リポジトリ `e-almighty/almighty` の中に置いて、**クラウドの Claude Code から使う**ときは、次の点だけ読み替えてください。
ツールやコマンドの中身・手順は変えていません。

## 1　APIキーは「チャットに貼らない」。環境の設定に入れる

キットの手順書には「キーをここに貼ってください」と書いてありますが、クラウドでは**チャットにキーを貼りません**。
次の2つを、**セッションのタイトルバーにあるクラウド環境メニュー → Edit（編集）**から設定します。

| 設定する場所 | 入れるもの |
|---|---|
| Network secrets（API credentials）または環境変数 | `ELEVENLABS_API_KEY`（必須）／`OPENAI_API_KEY`（任意） |
| Network access（Allowed domains） | `api.elevenlabs.io`／`api.openai.com`（Allow package managers はオンのまま） |

設定したあと、**新しいセッションを開くと反映**されます（開いているセッションには反映されません）。

ツールは `.env` ファイルからキーを読みます。クラウドでは、作業の最初に Claude が環境変数から `.env` を作ります。

```
cd 制作キット && printf 'ELEVENLABS_API_KEY=%s\nOPENAI_API_KEY=%s\n' "$ELEVENLABS_API_KEY" "$OPENAI_API_KEY" > .env
```

`.env` は `.gitignore` に入っているので、Git には入りません（**絶対に入れないこと**）。

## 2　この環境にすでに入っているもの

| | 状態 |
|---|---|
| Python 3 | 入っています |
| ffmpeg | 入っています |
| Google Chrome | **Chromium**（`/opt/pw-browsers/chromium`）が入っています。`make_slides.py` はこれを自動で見つけます |

`ツール/make_slides.py` には、Linux の Chromium を探す行と、管理者で動くときに必要な `--no-sandbox` を**足しただけ**です。Mac / Windows での動きは変わりません。

## 3　字幕のフォント（`/05_組み立て` で動画を作るとき）

`ツール/build_video.py` の `FONT = "Hiragino Sans"` は Mac のフォントです。
クラウド（Linux）には入っていないので、動画を組み立てる前に、この環境にある日本語フォント（`IPAPGothic` など）に書き換え、**字幕の大きさを測り直してください**（キットの第17章の注意どおり）。

## 4　保存されるもの・されないもの

| | Git に入る？ |
|---|---|
| `CLAUDE.md`・台本（`script.json`）・ツール・コマンド | 入る（コミットして push すれば次のセッションでも残る） |
| `.env`（キー） | **入らない**（毎セッション環境変数から作る） |
| `出力/`（音声・スライド・動画） | **入らない**（数GBになるため）。完成した動画は Dropbox などへ別途保存する |

クラウドのセッションは終わると中身が消えます。**残したいものはコミットして push** してください。

## 5　スラッシュコマンド

リポジトリのルートの `.claude/commands/` に、同じ名前のコマンド（`/はじめる`・`/動画をつくる` など）を置いてあります。
中身は「`制作キット/` の中の手順書を読んで、そのとおりに進める」という案内だけです。手順の本体は `制作キット/.claude/commands/` にあります。
