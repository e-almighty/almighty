# 制作キットの使い方

**本書は、PDFと制作キットの2つでできています。**
制作キットには、設計図・記入例・ツール・呼び出しコマンドが揃っています。

第2部を読みながら、これを埋めていってください。**白紙から書く必要はありません。**

---

## 1　制作キットの中身

```
制作キット/
├ 01_はじめる前の準備.md         ← ★契約・導入・キーの設定（最初にここ）
├ 02_制作キットの使い方.md       ← いま読んでいるもの
├ 03_困ったときの聞き方.md       ← ★エラーが出たら
├ 04_くわしい仕様.md             ← 寸法・書式・費用など、必要になったら
├ CLAUDE.md                    ← ★これが制作工場の設計図
├ .env.例                      ← APIキーの書き方
├ script_例.json               ← 台本データの見本（読み用／表示用つき）
├ スライドテンプレート.html      ← 1920×858（下222pxは字幕帯）
├ 企画書_記入例.txt             ← 埋めた実例（どの解像度で書くかの見本）
├ 台本_記入例.txt               ← 1行1文・読み用/表示用の書き方
├ ツール/
│   ├ compare_voices.py        ← 声を聞き比べる（第14章）
│   ├ make_slides.py           ← 台本 → スライド画像（第13章）
│   ├ make_voice.py            ← 台本 → 音声＋長さの計測（第14章）
│   ├ check_slides.py          ← ★箇条書きと字幕の重複を見る（第13章）
│   ├ check_voice.py           ← ★読み間違いを機械で洗い出す（第14章）
│   ├ subtitle_split.py        ← 字幕の割り方（build_video.py が使う）
│   ├ _api_error.py            ← エラーを日本語で説明する（各ツールが使う）
│   └ build_video.py           ← 全部 → 完成.mp4（第15章・第19章）
└ .claude/commands/            ← Claude Codeで「/名前」と打てば呼べます
    ├ はじめる.md               ← ★一度だけ（契約・設定・チャンネル設計）
    ├ 動画をつくる.md            ← ★毎回（会話で1本つくる）
    ├ チャンネルを増やす.md       ← 2つ目以降（第21章）
    ├ 00_声を選ぶ.md   01_構成.md   02_台本.md
    ├ 03_スライド.md   04_音声.md   05_組み立て.md
    └ 1本作る.md                ← 一言で全工程を走らせるコマンド
```

BGMを入れる場合は、制作用フォルダに `bgm/` という名前のフォルダを作り、
曲を5〜8曲入れてください。**あれば自動で使います**（第19章）。

## 2　この制作キットが作れるもの

先にはっきりさせておきます。

**制作キットが作るのは、スライド解説動画の1形式だけです。**

- 画面：スライド（見出しと箇条書き＋任意の絵）
- 声：ナレーション1人
- 字幕

**キャラクターの立ち絵、2人の掛け合い、顔出し、実写映像には対応していません。**

第1部でご紹介したツールを組み合わせれば、そうした動画も作れます。ですが**それは、この制作キットの外の話**です。

応用されるときは、**この制作キットを作り替えるのではなく、別の仕組みとして**組んでください。ここに手を入れると、スライド解説のほうが動かなくなります。

---

## 3　★本書をClaudeに読ませる必要はありません

先に、よくある勘違いをひとつ解いておきます。

**本書のPDFを、Claudeに読み込ませないでください。**

> **【図 B-1】役割のちがい**

| | 誰が読むか | 何のために |
|---|---|---|
| **本書（PDF）** | **あなた** | **なぜそうするのか**を理解するため |
| **制作キット** | **Claude** | **何をするか**の指示 |

本書は約15万字あります。読み込ませると、**動画を作り始める前に、会話の容量をほとんど使い切ってしまいます。**

**Claudeに必要な指示は、すべて制作キットの中に入っています。**本書を読んだあなたが理解している「なぜ」の部分は、Claudeには要りません。Claudeに要るのは「何をするか」だけです。

### 実際にやること

```
① 制作キットの中身を、制作用フォルダにまるごとコピーする
② そのフォルダで Claude Code を開く
③ 「/はじめる」と打つ
```

`CLAUDE.md` は、**Claude Codeが起動したときに自動で読み込まれます。**「これを読んで」と頼む必要はありません。

`.claude/commands/` の中身も、`/名前` と打った瞬間に読まれます。**普段は開くことも、中を覚えることもありません。**

---

## 4　覚えるのは、2つだけです

制作キットのファイルは多いですが、**実際に打つのはこの2つだけ**です。

> **【図 B-2】覚えるコマンド**

| | いつ | 何が起きるか |
|---|---|---|
| **`/はじめる`** | **一度だけ** | 契約・キーの設定・チャンネル設計・声決めを、順番に案内します |
| **`/動画をつくる`** | **毎回** | 「どんな動画を作りますか？」から始まり、完成まで会話で進みます |

残りのファイルは、この2つが内部で使うものです。**中身を覚える必要はありません。**

`/はじめる` は、**いまどこまで済んでいるかを先に調べます。**
すでに終わっていることは飛ばして、足りないところだけ聞いてきます。

## 6　最初にやること（3分）

1. **`制作キット` フォルダを、そのままClaude Codeで開きます**
   - 新しいフォルダを作ってコピーする必要はありません
   - フォルダ名は、チャンネル名に変えても構いません
2. Claude Codeを開いて、こう伝えます

> 「このフォルダに CLAUDE.md を置きました。読んでください。
> 　これから、ここに書いたルールに従って動画を作っていきます。」

「読みました」と返ってくれば、**あなたの制作工場が動き始めています。**

## 7　`CLAUDE.md` の埋め方

**このファイルが、本書でいちばん重要なファイル**です。

（　）の部分を、自分の内容に置き換えるだけです。順番はこうです。

| 埋める順 | どこ | 本書のどこを見るか |
|---|---|---|
| 1 | 企画（チャンネル名・テーマ・視聴者・差別化軸） | 第9章 9-3 |
| 2 | 話し手の人格（★例文3つ） | 第9章 9-4 |
| 3 | 台本の型 | 第9章 9-5 |
| 4 | **【固定・変更禁止】** | 第10章 10-2・10-4 |
| 5 | 画風（色・フォント・サイズ・絵柄） | 第13章 13-5／13-7 |
| 6 | 声（サービス・ID・速さ） | 第14章 14-1 |

> **⚠️ 【固定・変更禁止】だけは、必ず自分で書いてください**
> ここは、あなたが責任を負う一線です。**AIに提案させないでください。**
> 扱う分野の法令・規約を確認したうえで、ご自身の言葉で書いてください（第10章）。

### 埋め終わったかの確認

Claude Codeにこう聞くと、抜けを教えてくれます。

> 「CLAUDE.md を読んで、まだ（　）のまま残っている項目を挙げてください。」

## 8　画風の変え方

**画風を決める場所は、1つだけです。**

`ツール/make_slides.py` の上のほうにある **`STYLE`** を書き換えてください。

```python
STYLE = {
    "bg":     "#0f1830",   # 背景色
    "text":   "#ffffff",   # 文字色
    "accent": "#ffb02e",   # アクセント色（1色だけ）
    "font":   '"Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif',
    "h_size": 86,          # 見出しの大きさ（文字だけのとき）
    "b_size": 52,          # 箇条書きの大きさ（文字だけのとき）
    ...
}
```

> **★`スライドテンプレート.html` を書き換えても、動画には反映されません**
>
> テンプレートは、**1枚だけ手元で見た目を試すため**のファイルです。
> 実際のスライドは `make_slides.py` が `STYLE` を見て作ります。
>
> 色を試すときはテンプレートで見て、**決まったら `STYLE` に書き写してください。**

### 全シーンぶん、まとめて作られます

1枚ずつ作る必要はありません。

```
python3 ツール/make_slides.py script.json
```

これで全シーンぶんが `出力/slides/` に書き出されます。**15枚で30秒ほど**です。

### 触らないでほしい数値

- **1920×858** ── 下の222pxは動画側の字幕帯です。ここを変えると字幕と重なります
- **文字の大きさ** ── 大きさで収めようとせず、**台本の文字数のほうを短くしてください**
  （上限を超えると `make_slides.py` が警告を出します）

## 9　`/1本作る` の使い方（第16章まで進んだら）

`.claude/commands/1本作る.md` を置いてあると、Claude Codeで**一言**で呼び出せます。

> `/1本作る 5`

（5＝ネタマップの5番、という意味です）

これだけで、構成 → 台本 → スライド → 声 → 組み立て まで走ります。

**途中、構成ができた時点で必ず一度止まります。**そこで確認してから先に進んでください（第16章 16-6）。

### 自分用に書き換える

`1本作る.md` は**日本語の手順書**です。プログラムではありません。

「もっと早く止まってほしい」「この工程を飛ばしたい」と思ったら、**文章を書き換えるだけ**です。

## 10　うまくいかないときの確認順

| 症状 | まず見るところ |
|---|---|
| ルールが守られない | `CLAUDE.md` を読み込めているか（「CLAUDE.mdを読んで」と頼む） |
| 画風が毎回違う | `CLAUDE.md` の画風の欄が埋まっているか |
| `/1本作る` が反応しない | `.claude/commands/` の中にファイルがあるか（点で始まるフォルダ名に注意） |
| 字幕がスライドに重なる | スライドが **1920×858** になっているか（`make_slides.py` の `TPL` の width/height） |
| 読み調整が字幕に出てしまう | 台本に「表示用／読み用」を分けて書いているか（第14章） |
