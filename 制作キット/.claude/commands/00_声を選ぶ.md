チャンネルで使う声を決めます。**これは1本目を作る前に、必ずやってください。**

## なぜ最初なのか

**声はあとから変えると、全編を作り直すことになります**（第14章 14-1）。
画像なら1枚だけ差し替えられますが、声はチャンネルの印象そのものだからです。

## 手順

**① まず、おすすめ6声を聞き比べる**

```
python3 ツール/compare_voices.py --おすすめ
```

`出力/声比較/` に6つのmp3が並びます。
どれも **ElevenLabsの共有ライブラリにある日本語の声**です。
**Creatorプランがあれば、追加手続きも追加料金もなく、そのまま使えます**（実測で確認済み）。

**数字だらけの文を読ませて、誤読しないか確かめてあります**（2026年10月）。
**Creatorプランがあれば、追加手続きなしでそのまま使えます。**

| 声 | 系統 | 読み上げの速さ | 数字の読み |
|---|---|---|---|
| **Mitsuki** | 女性・若・明るめ | **229字/分** | すべて正確 |
| Yuki | 女性・若 | 264字/分 | **「十か月」を誤読** |
| **Haru** | 女性・穏やか | 290字/分 | すべて正確 |
| **Kana** | 女性・落ち着き | **327字/分** | すべて正確 |
| **Ryu** | 男性・中年・落ち着き | 280字/分 | すべて正確 |
| **Riku** | 男性・中年・深め | 292字/分 | すべて正確 |

### ★2つ、先にお伝えします

**① 声によって、尺が4割変わります**

MitsukiとKanaでは、同じ原稿でも**尺が1.4倍**違います。
10分の動画なら、Mitsukiで約2,300字、Kanaで約3,300字。**千字の差**です。

**声を決めてから、台本の長さを決めてください。**

**② 誰に向けたチャンネルかで選んでください**

| 視聴者 | 向いている声 |
|---|---|
| 年配の方 | 落ち着いた中年の声（Ryu・Riku） |
| 若い方・テンポ重視 | 明るめの若い声（Mitsuki・Yuki） |
| 長時間の解説 | 穏やかな声（Haru・Kana） |

**同世代の声のほうが届きやすい**傾向があります。

**★別の声を選ぶときに、必ず見るもの**

一覧には「取り下げの予告期間」があります。提供者がその声を引き上げるとき、
**どれだけ前に知らせてくれるか**です。

| 予告期間 | 判断 |
|---|---|
| 730日（2年） | ○ おすすめ（上の6声はすべてこれ） |
| 180日 | △ まだ対応できる |
| **30日** | **× 避けてください** |

チャンネルの声が1か月後に使えなくなると、**全動画の声が揃わなくなります。**

**② 気に入るものがなければ、一覧から探す**

```
python3 ツール/compare_voices.py
```

共有ライブラリの日本語の声が、**使われている数の多い順**に40件出ます。
気になるIDを選んで、聞き比べます。

```
python3 ツール/compare_voices.py （ID1） （ID2） （ID3）
```

**③ 通しで聞いて、選ぶ**

決めたら、**`CLAUDE.md` の「声」と `script.json` の `voice_id` に書いてください。**
テンプレートは空欄にしてあります。**既定の声はありません。必ずご自身で選んでください。**

## ★選ぶときの注意

- **5秒で決めないでください。**どの声も、最初の数秒は自然に聞こえます
- **最後まで通しで聞いてください。**差が出るのは後半です
  - 抑揚のパターンが繰り返されて、単調に感じないか
  - 文の切れ目の「間」が、いつも同じ長さになっていないか
  - **日本語として不自然な訛りが混じっていないか**
- できれば**スマートフォンのスピーカー**で聞いてください。視聴者の多くはその環境です
- 比較用の原稿は、`ツール/compare_voices.py` の `SAMPLE` を**自分のチャンネルの台本**に差し替えると、より正確に判断できます

> **⚠️ 共有ライブラリの声を使うときの注意**
> 日本語ラベルが付いていても、**日本語話者が聞くと訛りを感じる声が混じっています。**
> ラベルや説明文で選ばず、**必ず自分の耳で確かめてください。**
> 上の「おすすめ6声」は、実際に聞いて選んだものです。

## 決まったら

その `voice_id` を、次の2か所に書いてください。

1. `CLAUDE.md` の「制作の設定 → 声」
2. `script.json` の `voice_id`

これで、2本目からは「基本設計の声で」の一言で済みます。
