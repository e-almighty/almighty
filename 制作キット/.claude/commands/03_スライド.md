`script.json` から、スライド画像を作ってください。

## やること

```
python3 ツール/make_slides.py script.json
```

これを実行するだけです。`出力/slides/` に `slide01.png` から順番に書き出されます。

## 画風を変えたいとき

`ツール/make_slides.py` の上のほうにある `STYLE` を書き換えてください。
`CLAUDE.md` の「制作の設定」と同じ値にしてください。

```python
STYLE = {
    "bg": "#0f1830",       # 背景色
    "text": "#ffffff",     # 文字色
    "accent": "#ffb02e",   # アクセント色
    "font": '"Hiragino Sans", ...',
    "h_size": 86,          # 見出しの大きさ
}
```

## 守ること
- **文字・数字・図の構造は、絵に描かせないでください。**AIは数を数えられず崩れます（第13章）
  （雰囲気の絵を添えるのは可。`art` に指示を書くと右側に入ります）
- **スライドは1920×858で作ります。**下の222pxは動画側の字幕帯です
- 全シーンを**1回でまとめて**作ってください。1枚ずつ作ると設定がぶれます

## 出したあと
枚数を報告し、**全部のスライドを目で確認してください**と伝えてください。
確認するのは「文字が画面からはみ出していないか」「箇条書きが1行に収まっているか」です。

はみ出していた場合は、**スライドの文字を小さくせず、`script.json` の文字数を減らしてください。**


---

> **スライドは 1920×858 で作ります。**残りの下222pxは字幕帯です（第15章）。
> 字幕はその帯の中に入るので、**スライドの中身と重なりません。**

## 絵を入れる場合（任意・第13章）

`script.json` の各シーンに `"art"` があり、`.env` に `OPENAI_API_KEY` があれば、
**自動で絵を作って右側に置きます。**なければ文字だけで作ります。

```json
{ "heading": "基礎控除はいくら？", "art": "電卓と家と家族3人のアイコンが並ぶ図", "bullets": […] }
```

### 守ること

- **文字・数字は絵に描かせません。**必ずHTMLで描きます
  - AIに数字を描かせると、台本と違う数字を勝手に描くことがあります
- **絵ありのときは、文字数の上限が変わります**（見出し12字・箇条書き17字）
  - 超えると2行に折れます。折れて困る場合は文字を減らしてください
- 費用は**1枚1円ほど**（quality `low`）。15枚で約14円です
- **同じ指示の絵は作り直しません。**文字だけ直すなら0円です

### 絵の指示の書き方

- 「何が描かれているか」だけを書く（20〜40字）
- **色や画風は書かない**（`ART_STYLE` で全体を揃えているため）
- 例：「書類とパソコンとデータベースが矢印でつながる図」
