確定した構成をもとに、台本を書いてください。

## つくるもの
`script.json` というファイルを作ってください。形式は `script_例.json` と同じです。

```json
{
  "title": "（動画のタイトル）",
  "channel": "（チャンネル名）",
  "voice_id": "（CLAUDE.md の声のID）",
  "scenes": [
    {
      "heading": "（スライドの見出し・18字以内）",
      "section": "（台本の型の区切り名。導入／結論提示／ポイント1／まとめ など）",
      "art": "（任意。絵を入れるなら、何を描くかを20〜40字で）",
      "bullets": ["（25字以内。★ナレーションの言い換えにしない）", "（同上）", "（同上）"],
      "lines": [
        {"text": "（ナレーション1文）"},
        {"text": "（表示用の文）", "read": "（読み用の文）"}
      ]
    }
  ]
}
```

## 守ること

**① ナレーションは「1行に1文」**
- `lines` の1要素が、1つの文です。**1つの要素に2文入れないでください**
- この1行が、音声1つ・字幕1つになります。ここが崩れると後の工程が全部崩れます
- **一文は40字以内。**長くなる場合は文を分けて、要素を増やしてください

**② 読み調整が必要な行だけ `read` を足す**
- 数字・固有名詞など、読み間違えられそうな箇所がある行にだけ書きます
- `text` ＝ 画面に出す文（そのまま読める表記）
- `read` ＝ 音声に読ませる文（例：3,000万円 → 三千万円）
- **必要のない行に `read` を書かないでください**

**③ 見出しと箇条書き**
- 見出しは18字以内、箇条書きは3つまで・1つ25字以内
- **箇条書きとナレーションで同じ文を繰り返さないでください。**箇条書きは要点、ナレーションは説明です

**④ CLAUDE.md の設定に従う**
- 話し手の人格（一人称・二人称・口調）を、最後の1行まで崩さないでください
- 【固定・変更禁止】のルールに、すべて従ってください
- 読み上げ前提の日本語で書いてください（硬い接続を使わない／同音異義語を避ける）

## 出したあと
### ★箇条書きは、ナレーションの言い換えにしないでください

**ナレーションは字幕で全文が画面に出ます。**箇条書きにも同じことを書くと、画面に同じ内容が2回出ます。

箇条書きは要約ではなく、**あとで思い出したい形**で書いてください。

| | 例 |
|---|---|
| ○ 数式 | 3,000万円＋600万円×人数 |
| ○ 数字 | 期限は10か月 |
| ○ 用語 | 基礎控除／代襲相続 |
| ○ 手順の骨 | ① 相続人の数　② 枠の計算 |
| **× 言い換え** | **全員にかかるわけではない** |

**3つ埋めようとしないでください。**書くことがなければ減らします。見出しだけの画面があっても構いません（第13章 13-1）。

書けたら、必ず確認してください。

```
python3 ツール/check_slides.py script.json
```

### `section` の付け方（第19章）

`/01_構成` で決めた**台本の型の区切り**を、そのまま入れてください。

| 台本の型 | 入れる区切り |
|---|---|
| 結論3つ先出し | 導入／結論提示／ポイント1／ポイント2／ポイント3／まとめ |
| 悩み解決 | 導入／悩みの提示／原因／解決策／まとめ |
| ビフォーアフター | 導入／いまの状態／変化後／方法／まとめ |
| 謎引っぱり | 導入／疑問／深掘り／答え／まとめ |
| ○個まとめ | 導入／1つ目／2つ目／…／まとめ |

同じ区切りが続くシーンは、まとめて1つの区切りとして扱われます。
**ここでBGMが切り替わります。**話の構造が、音でも伝わるようになります。

`script.json` を保存し、あわせて**人が読み返すための `台本.txt`** も出力してください。
そのうえで、次を報告してください。

- シーン数／行数／読み上げ文字数
- **推定の尺**（読み上げ文字数 ÷ その声の字/分 × 60秒）
  - ※ `CLAUDE.md` で決めた声の速さを使ってください
  - ※ 実測：Mitsuki 229／Yuki 264／Ryu 280／Haru 290／Riku 292／Kana 327（字/分）
  - ※ **いちばん遅い声と速い声で、同じ台本でも尺が1.4倍違います**
  - 一度でも音声を作ったことがあれば、`/04_音声` が報告した**実測の字/分**を使ってください

そして、こう伝えてください。
「**台本を声に出して読んでみてください。**引っかかる箇所があれば直します。」
