`script.json` から、音声を作ってください。

## 前提
- `.env` に `ELEVENLABS_API_KEY=（キー）` があること
- `script.json` に `voice_id` が入っていること

## やること

```
python3 ツール/make_voice.py script.json
```

`出力/voice/` に **1行につき1つ** のmp3が作られ、`出力/durations.json` に各行の秒数が保存されます。

> **⚠️ モデルと言語の指定を、絶対に省略しないでください**
> `make_voice.py` は `eleven_v3` ＋ 言語 `ja` を指定しています。**ここを変えないでください。**
> 古いモデルや言語指定なしだと、**漢字を中国語と誤判定**します。
> 実際に起きた例：「十四日以内」→「しいしにち以内」／「三千万円」→「三千万**元（マーゲン）**」
> ElevenLabsのサイトから使うときは自動で設定されますが、**APIでは自分で指定する必要があります。**

## 仕組み（覚えておいてください）
- 音声には **`read` があればそれを、なければ `text`** を使います
- 1行ずつ作るので、**直したい行だけ作り直せます**（そのファイルを消して再実行）
- すでにあるファイルは作り直しません。無駄な費用が出ないようにしています

## 出したあと ①　機械で読み間違いを洗い出す（任意）

```
python3 ツール/check_voice.py script.json
```

> この工程は**任意**です。OpenAIのキーがある場合だけ動きます（1本あたり10円ほど）。
> キーが無ければ、そのまま次へ進んでください。**通しで聞くほうが本体**です。

作った音声を文字起こしして、台本と突き合わせます。
**数字・固有名詞の読み間違いが、聞く前に一覧で出ます。**

- `⚠ 数字が違います` → **必ず直してください**
- `・語の確認` → 文字起こし側の表記ゆれのこともあります。その行だけ聞いて判断してください

出た行を報告し、直し方（下記）を提案してください。

> これは**耳の代わりではありません。**10分の動画で全行に集中するのは難しいので、
> **怪しい行を先に絞り込む**ためのものです。

## 出したあと ②　通しで聞いてもらう

必ず次を報告してください。
- 行数／読み上げ文字数／合計の尺／読み上げ速度（字/分）
- `check_voice.py` の結果

そして、こう伝えてください。

「**通しで聞いてください。**1行ずつではなく、最初から最後までです。
気になる箇所があったら、**誤読か抑揚か**を教えてください。直し方が違います（第14章）。」

## 間（ま）について

**この工程では、行のあいだの無音は入りません。**間は組み立て（`/05_組み立て`）で入ります。

ですので、ここで聞くときは**1行ずつが自然かどうか**だけを見てください。
「つなげたら早口だった」は、組み立てのあとに判断します（第14章 14-7）。

## 直すとき

**誤読（別の言葉として読まれた）**
→ `script.json` のその行に `read` を足して、ひらがなで読みを固定する
→ その行のmp3を削除して、もう一度実行する

**抑揚が変（読みは合っている）**
→ `read` の表記を言い換える（例：高配当 → コーハイトー／ここで一度 → ここで 一度）
→ **いきなりひらがなにしないでください。**平板になります

どちらの場合も、**`text` は変えないでください。**字幕に出るのは `text` です。
