スライドと音声を、1本の動画にまとめてください。

## 前提
`出力/slides/` にスライド、`出力/durations.json` に音声の長さがあること。
まだなら、先に `/03_スライド` と `/04_音声` を実行してください。

## やること

```
python3 ツール/build_video.py script.json
```

`出力/完成.mp4` ができます。

## 中で何をしているか（第15章・第19章）

1. 各音声を無圧縮に直して、**実測で**長さを測る
   - ★mp3をそのままつなぐと1ファイルごとにわずかに伸び、終盤で字幕がずれます
2. シーンごとに合計して、**その秒数だけスライドを表示する**
3. **行のあとに「間」を入れる**（句点0.40秒／読点0.25秒／シーンの最後0.70秒）
   - ★これを入れないと、つないだ瞬間に早口になります（第14章 14-7）
   - そのぶん尺が伸びます（1行あたり約0.47秒）
4. **字幕を「めくる単位」に割って出す** ── **字幕は `text`（表示用）を使います**
   - **必ず1行**（2行にしない）／28字まで／**1枚1.4〜3.0秒**
   - **単語の途中で切らない**（句読点・助詞・文末表現のうしろだけで切る）
   - **音声が息をつぐ場所を検出して、そこでめくる**（声とずれません）
   - 字幕は下222pxの帯の中。スライド（上858px）と重なりません
5. `bgm/` があれば、**台本の区切りごとに曲を割り当てる**（第19章 19-2）
   - 切り替わりは**1.5秒重ねる**（19-3）
   - 喋っている間だけ**8％→約1〜2％に自動で下げる**（19-4）
6. 全部つないで、字幕を焼き込んで書き出す

**画を音声に合わせています。逆ではありません。**だから手で詰める作業がありません。

## BGMについて（第19章）

制作用フォルダに `bgm/` を作って曲を入れておくと、**自動で使います。**ないときはBGMなしで作ります。

曲を切り替える区切りは、`script.json` の各シーンの `"section"` で決まります。

```json
{ "heading": "…", "section": "導入", "bullets": […] }
```

同じ `section` が続くシーンは、ひとまとまりとして同じ曲になります。
台本の型の区切り（導入／結論提示／ポイント1／…／まとめ）をそのまま入れてください。

**1本に1曲を流し続けないでください。**いちばん多い失敗です（19-2）。

## 出力の設定
1920×1080 ／ 30fps ／ H.264（yuv420p）／ 音声 AAC 192k
YouTubeにそのまま投稿できる形式です。

## 出したあと

### ★確認のしかた（重要）

字幕が本当に進んでいるかは、**ファイルを見ても分かりません。**
**同じスライドの中で**、数秒おきに画像を抜き出して確かめてください。

```
ffmpeg -ss 1 -i 出力/完成.mp4 -frames:v 1 /tmp/a.png
ffmpeg -ss 3 -i 出力/完成.mp4 -frames:v 1 /tmp/b.png
```

スライドをまたぐ時刻だけ見ると、変わっているように見えてしまいます。

尺・シーン数・字幕カット数を報告し、**必ずこう伝えてください。**

「**最初から最後まで再生して確認してください。**とくに**末尾**です。
いちばん多い失敗が『最後の数秒が切れている』です。」

## つまずいたとき

| 症状 | 対処 |
|---|---|
| **字幕がスライド1枚につき1つしか出ない** | **処理の順番**。字幕を焼く前に30コマ／秒にする（第15章 つまずき⓪） |
| 字幕が □ になる | `build_video.py` の `FONT` を、そのパソコンにある日本語フォント名に変える |
| 字幕が背景に溶ける | 起きません（帯の中に入るため）。帯の色は `BAND_COLOR` で変えられます |
| 字幕のめくりが速すぎる | `subtitle_split.py` の `MAX_SEC` を大きくする（3.0→3.5など） |
| 話し方が早口に聞こえる | `build_video.py` の `GAP_PERIOD` を大きくする（0.40→0.50など） |
| 間延びして聞こえる | 同じく `GAP_` の値を小さくする |
| 字幕がスライドに重なる | 起きません（帯が別枠のため）。重なるならスライドが1920×858でない |
| 最後のスライドが一瞬で消える | 既知の挙動。スクリプトは対処済み。それでも出たら報告してください |
| 音と画がずれる | `durations.json` を使わず推定していないか確認する |
| BGMが入らない | `bgm/` フォルダが制作用フォルダの直下にあるか確認する |
| BGMがうるさい／小さい | `build_video.py` の `BGM_VOL` `BGM_DUCK` を調整する。**判断は翌日にスマホのスピーカーで**（19-4） |
| 曲が途中で変わらない | `script.json` の各シーンに `"section"` が入っているか確認する |
