2つ目以降のチャンネル用に、**新しい制作フォルダを作ってください。**

> このコマンドは、**1つ目が回りはじめてから**使うものです。
> 初めての方は `/はじめる` を使ってください。

## あなたの役割

**いま作業しているフォルダには、いっさい手を触れないでください。**
新しいフォルダは、**隣に**作ります。

- ★**いまのフォルダの名前を変えない・移動しない**（ファイルが見えなくなります）
- ★**`出力/` はコピーしない**（音声と画像で数GBになります。中身も混ざります）
- コピーが終わったら、**必ず新しいフォルダで開き直してもらう**

---

## ステップ1　増やしていい状態か、確かめる

**先に、これを聞いてください。**

> 「2つ目を作る前に、1つだけ確認させてください。
> **1つ目のチャンネルで、動画を10本出しましたか？**」

**10本出していない場合は、止めてください。**

> 「まだでしたら、**2つ目はおすすめしません。**
>
> 理由は3つあります（本の第21章）。
> ・1つ目の型が固まる前に増やすと、どちらも中途半端になります
> ・確認の手間は本数ぶん増えます。倍になるのは作業だけです
> ・伸びない原因が「本数不足」なのか「設計」なのか、判断できなくなります
>
> それでも進めますか？」

**「進める」と言われたら進めてください。**止めるのはここまでです。

---

## ステップ2　新しいチャンネルの名前を聞く

> 「新しいチャンネルの名前を教えてください。
> フォルダ名になります。**日本語で構いません。**」

聞いた名前で、**いまのフォルダと同じ階層に**フォルダを作ります。

```
（親フォルダ）/
├ お金の相談室/        ← いまここで作業しています
└ （新しい名前）/      ← ここに作ります
```

同じ名前のフォルダがすでにあれば、**上書きせずに聞き直してください。**

## ステップ3　引き継ぐものだけをコピーする

**引き継ぐもの**

| | なぜ |
|---|---|
| `ツール/` | 工程は完全に同じ（第21章 21-2） |
| `.claude/commands/` | 手順も完全に同じ |
| `.env` | APIキーは共通。取り直す必要はありません |
| `スライドテンプレート.html` | 仕組みは同じ。**色だけ後で変えます** |
| `script_例.json`・記入例2つ | 書き方の見本 |
| `01_`〜`04_` のmdファイル | マニュアル |

**引き継がないもの**

| | なぜ |
|---|---|
| **`出力/`** | ★前のチャンネルの音声・画像。**数GBあり、中身も混ざります** |
| `script.json` | 前の台本 |
| `bgm/` | 世界観が違えば曲も変わります（第19章）。必要なら後で入れます |

コピーが終わったら、**新しいフォルダに `出力/` が無いことを確認してください。**

## ステップ4　`CLAUDE.md` を、新しいチャンネル用に戻す

**ここがいちばん大事です。**前の内容が残っていると、**2つ目が1つ目の劣化版になります。**

コピーした `CLAUDE.md` の、次の欄を**空（　）に戻してください。**

| 戻す欄 | 理由 |
|---|---|
| チャンネル名・テーマ・説明 | 全部違います |
| 想定視聴者（年齢層・立場・悩み） | 全部違います |
| 差別化軸 | 全部違います |
| 台本の型 | 選び直します |
| 話し手の人格（名前・一人称・口調・例文3つ） | ★**ここを残すと、声だけ変えた同じ人になります** |
| 【固定・変更禁止】 | ジャンルが違えば、守る一線も違います |
| 声（voice_id） | ★変えます |
| 締めの導線（送客先・特典） | 違います |

**そのまま残す欄**

- 画面の分け方・文字サイズ・字幕の設定・音量・出力形式（工程は同じ）
- 【調整可】の表現のルール（一文40字以内、など）
- **画風の色だけは、あとで変えてもらいます**（仕組みは同じ）

## ステップ5　開き直してもらう

**★ここを飛ばさないでください。**

> 「新しいフォルダができました。
>
> ```
> （新しい名前）/
> ```
>
> **ここからは、私はまだ前のフォルダを見ています。**
> お手数ですが、**Claude Codeをいったん閉じて、新しいフォルダで開き直してください。**
>
> 開き直したら、そこで **`/はじめる`** と打ってください。
> 契約とキーは済んでいるので、**チャンネル設計と声だけ**を決めていきます。
> 15分ほどです。」

**新しいフォルダの中身を、この場で編集し続けないでください。**
利用者が開き直したあと、そちらのClaudeが続きをやります。

## ステップ6　1つ目の学びを渡す

開き直してもらう前に、**これだけ伝えてください。**

> 「最後に1つ。1つ目のチャンネルで**うまくいったこと・失敗したこと**を、
> メモしておいてください。新しいフォルダで `/はじめる` を進めるときに貼ると、
> **同じ失敗を1回ぶん飛ばせます。**（第21章 21-5）
>
> 例：
> ・視聴維持率が落ちる場所は、だいたい〇分あたりだった
> ・この言い方は伸びなかった
> ・この声は、この視聴者には合わなかった」

## やってはいけないこと

- **いま作業しているフォルダの名前を変える・移動する**
- **`出力/` をコピーする**
- **`CLAUDE.md` の人格と声を、そのまま残す**
- 開き直してもらわずに、新しいフォルダの中身を作り続ける
- 10本出していない人を、確認なしで先に進める
