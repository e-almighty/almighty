## 3　② Claude Code を入れる

ここが、いちばん身構えられる部分だと思います。**やることは、ひとつのアプリを入れるのと同じ**です。

### 手順

1. ブラウザで **https://claude.com/claude-code** を開きます
2. お使いのパソコン（Windows / Mac）に合わせた案内に従って導入します
3. 導入が終わったら、**Claude Codeを開いて、最初に一度ログイン**します
   - ①で作ったアカウントでログインしてください

### 開き方

導入すると、パソコンで**「Claude Code」を開く**ことができるようになります。

開くと、**文字を打ち込む画面**が出ます。ここに日本語で頼みます。それだけです。

> **⚠️ 最初に必ずやること**
> 開いたら、まず次のように打ち込んでみてください。
>
> 　`こんにちは。準備できていますか？`
>
> 返事が返ってくれば、準備は完了です。返ってこない場合は、ログインができていません。

### うまくいかないとき

**画面に出ているエラーの文章を、そのままコピーしてClaudeに貼ってください。**（ブラウザのClaudeで構いません）

> 「Claude Codeを入れようとしたら、こう出ました。どうすればいいですか。
> 　（エラーの文章を貼る）
> 　私のパソコンは（Windows / Mac）です。」

これがいちばん早い解決方法です。**エラー文をそのまま貼る**のがコツです。

## 4　③ ElevenLabsの有料プランに申し込む

音声を作るサービスです（第3章）。

1. ブラウザで **https://elevenlabs.io/** を開きます
2. アカウントを作ります
3. 右上の自分のアイコン →「Subscription」を開きます
4. **Creator（月22ドル前後）**を選びます

> **★Creatorより下のプランは選ばないでください**
> 本書はCreatorを前提にしています。下のプランだと、
> **商用利用ができない／文字数が足りない／使えない声がある**のいずれかで止まります。

> **無料プランでは進めません**
> 無料プランは**商用利用ができず**、月間の文字数も動画1本ぶんで尽きます。
> YouTubeで収益化するなら、生成した音声は商用利用にあたります（第3章 3-2）。

### APIキーを取得する

ツールから音声を作るのに、**キー**という文字列が必要です。

1. 右上の自分のアイコン →「API Keys」を開きます
2. 「Create API Key」を押します
3. 表示された文字列を**コピー**します（`sk_` で始まります）

> **⚠️ このキーは、他人に見せないでください**
> キーを知っている人は、あなたの残高で音声を作れてしまいます。
> 画面共有や、SNSへの投稿にご注意ください。

### キーを、制作用フォルダに置く

制作キットの `.env.例` というファイルを、**`.env` という名前でコピー**して、そこに貼り付けます。

やり方がわからなければ、Claude Codeにこう頼んでください。

> 「制作キットの `.env.例` を `.env` という名前でコピーして、ElevenLabsのキーを設定してください。キーはこれです：（貼り付ける）」

## 7　⑥ Python 3 を入れる

`ツール/` の中身は Python で動きます。**入っているか、まず確かめてください。**

```
python3 --version
```

`Python 3.○.○` と出れば済んでいます。

**出ない場合**

- **Mac**：`xcode-select --install` を実行（Appleの開発ツールに含まれています）
  - それでも入らなければ https://www.python.org/ から
- **Windows**：Microsoft Store で「Python 3」を検索して入れる
  - または https://www.python.org/ から。**インストール画面の「Add python.exe to PATH」に必ずチェック**を入れてください

> **★Windowsの方へ**
> Windowsでは `python3` ではなく **`py`** で動くことがあります。
> `python3` で「見つかりません」と出たら、**`py` に置き換えて**試してください。
>
> 例：`py ツール/make_slides.py script.json`

## 8　⑦ 制作キットの置き場所を決める

最後です。**新しくフォルダを作る必要はありません。**

> **★ダウンロードした `制作キット` フォルダが、そのまま制作用フォルダです。**
> 中身をどこかにコピーする必要も、移し替える必要もありません。

### 手順（★Claude Codeを開く**前**にやってください）

1. ダウンロードした **`制作キット` フォルダを、デスクトップに置きます**
2. 名前を、**チャンネル名（または好きな名前）**に変えます
   - 例：`お金の相談室`
   - **日本語で構いません。**変えなくても動きます

> **⚠️ フォルダ名を変えるなら、Claude Codeを開く前に**
>
> Claudeは、**開いたときのフォルダの場所を覚えます。**
> 開いたまま名前を変えたり、別の場所へ動かしたりすると、
> Claudeは**前の場所を見にいって「ファイルがありません」と言い出します。**
>
> **直し方は簡単です。**
> Claude Codeを閉じて、**新しい名前のフォルダで開き直すだけ**。
> **作ったものは1つも消えていません。**

これで準備は終わりです。

### Claude Codeに、このフォルダを見せる

Claude Codeを開いたら、**このフォルダで作業してほしい**と伝えます。

いちばん簡単なのは、**フォルダをClaude Codeの画面にドラッグして入れる**方法です。
うまくいかないときは、こう頼んでください。

> 「デスクトップの『（フォルダ名）』というフォルダで作業してください。」

**そのフォルダの中に `CLAUDE.md` があれば、Claudeが自動で読みます。**
ここまで来たら、あとは `/はじめる` と打つだけです。

## 10　この先で出てくる言葉

本編で説明なしに出てくる言葉を、先にまとめておきます。**覚える必要はありません。**「そういうものか」と思っていただければ十分です。

| 言葉 | 読み | どういうものか |
|---|---|---|
| **プロンプト** | ── | AIに送る指示の文章のこと |
| **ffmpeg** | エフエフエムペグ | 動画をつなげる無料のツール。使い方は覚えなくていい |
| **HTML** | エイチティーエムエル | 画面の見た目を書くための書式。書くのはClaudeです |
| **px（ピクセル）** | ── | 画面の点の数。文字の大きさを表す単位 |
| **1920×1080** | ── | 画面の大きさ。テレビと同じ横長の比率（フルHD） |
| **#0f1830** のような記号 | ── | 色を表す番号。自分で考えず、選んだ色をコピーするだけ |
| **mp4** | エムピーフォー | 動画ファイルの形式 |
| **png** | ピング | 画像ファイルの形式 |
| **.txt / .md** | ── | 文字だけを保存する形式。メモ帳で作れます |
| **焼き込む** | ── | 字幕を映像そのものに描き込むこと。消せなくなる代わり、どこでも必ず表示される |
| **30fps** | ── | 1秒間に30枚の絵で動かすということ |
| **尺（しゃく）** | ── | 動画の長さ |
| **導線・送客** | ── | 見た人に次にどこへ行ってもらうか |
| **利用枠** | ── | 一定時間内に使える量の上限。超えると少し待つことになる |

## 11　困ったときの、いちばん確実な方法

本編を読み進めていて、わからなくなったら。

**その箇所を、そのままClaudeに貼ってください。**

> 「『AI動画生成大全』という本を読んでいます。
> 　次の部分の意味がわかりません。かみ砕いて説明してください。
> 　（本文をコピーして貼る）
> 　私は（　　）の経験がありません。」

本書のプロンプトはすべてコピーして使えるように書いてありますが、**わからない箇所を貼って聞く**という使い方が、実はいちばん効きます。

**遠慮なく、何度でも聞いてください。**それがこの制作キットの使い方です。
